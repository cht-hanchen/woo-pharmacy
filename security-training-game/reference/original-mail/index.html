01

什麼是電子郵件社交工程

目的：引誘你開附檔、點連結

社交工程的主要目的，就是引誘收信人使用郵件的附檔，或點選惡意連結，以便竊取資料。現在郵件的附檔除了執行檔可能是木馬程式外，連 Office、圖片相片、音樂檔都可能內含惡意程式；郵件中的網頁連結，也可能連到藏有惡意程式的網頁，使用者在瀏覽網頁的同時就被植入惡意程式，進而被竊取個人資料，或被當成跳板機。

05

處理郵件與防護設定

收到信之後

  1. 先看寄件者確認 @ 後面的網域，主旨有沒有 [外部郵件] 標記。
  2. 再看主旨是否和你的業務有關？若無相關，建議刪除，不要開啟。
  3. 不點非公務網址、不開非公務附檔即使內文看起來無害，附檔與連結才是真正的陷阱。
  4. 不確定就通報交給單位資安幫手確認，不要自己點開測試。

建立加密郵件

什麼時候要加密

機密級以上

機密級以上資料傳輸時，應採行具加密機制之電子郵件服務。

極機密級

未經權責主管授權，不得使用電子郵件傳送。

寄給外部

少量機敏文件需提供給外部時，請使用安全電子郵件，不使用 LINE、Google Drive 等外部服務。

取得電子郵件簽章與加密軟體

EIP 企業入口網站→資源共享→軟體下載→資安軟體→電子郵件簽章與加密

安裝後即可在撰寫郵件時加上數位簽章與加密。收件人可以確認信件確實由你寄出，且內容在傳送途中不會被他人讀取。

中華電信資通安全處每年執行 2 次無預警電子郵件警覺性測試。

全區目標< 1%

測試信的點閱率與開啟連結率都要低於 1%。

違規管理累計面談

依〈新北營運處個人終端違規管理辦法〉，社交工程誤點擊依年度累計次數面談。

測試信混在一般信件裡，靠眼睛判斷難免失手。先把 Outlook 設定好，讓外部郵件分開放、點標題不會自動開信、圖片不會自動下載、內容以純文字顯示，就算不小心點到，也比較不會中招。自檢就是確認這些設定都還在。

誤點擊的面談層級

第 1 次違反科長（主任）面談
第 2 次違反副總經理面談
第 3 次違反總經理面談

各管控項目之累積次數依年度分開計算。權責主管接獲事件單通知或社交工程誤點擊名單後，需通知當事人進行面談並填寫面談紀錄表，轉送資通科製作月報表追蹤。

封鎖外部圖片

自檢表名稱：封鎖外部圖片

信件中的圖片可以回報「你已開信」，也可能被用來確認你的信箱是有效的。不自動下載就不會被追蹤。

檔案→選項→信任中心→信任中心設定→自動下載→勾選「不要自動下載圖片」

自檢表名稱：以純文字格式檢視

檔案→選項→信任中心→信任中心設定→電子郵件安全性→勾選「以純文字讀取所有標準郵件」

QA

常見問答

主旨有 [外部郵件] 的信都不能開嗎？
不是。客戶、廠商寄來的公務信也會標示 [外部郵件]。重點是確認寄件者是否為你認識的業務往來對象、主旨是否和你的業務有關；兩者都對得上才處理，否則刪除或通報。
寄件者顯示公司同仁或長官的名字，就安全嗎？
不一定。顯示名稱可以隨意假造，請看 @ 後面的網域是否為 @cht.com.tw。內容不尋常（例如要求緊急匯款、提供密碼、點連結驗證帳號）時，請另外以電話向本人確認。
只是點開信件、沒點附檔，會有事嗎？
有開啟郵件預覽或顯示外部圖片時，開信本身就可能被追蹤。請依第五章完成關閉預覽、封鎖外部圖片、以純文字檢視等設定。若已點了連結或附檔，請立即拔除網路線並通報。
不小心點了社交工程測試信怎麼辦？
誤點擊會被計入營運處 BSC 考評與個人考核。點了之後不要自行處理，請通報單位資安幫手，並檢查電腦是否有異常。
可疑郵件可以轉寄給同事問問看嗎？
不要。轉寄會讓更多人收到惡意附檔或連結。請直接通報單位資安幫手，由他協助確認。
