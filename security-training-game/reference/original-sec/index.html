為什麼這很重要

我們是駭客組織覬覦的重點目標。

  • 公司屬於資通安全管理法中「關鍵基礎設施」的通訊類。
  • 公司能安然度過勒索軟體的攻擊，靠的是每位同仁落實資安政策並自律（例如：禁用網路芳鄰）。

遵守公司資安政策，既是保護公司的資產，也是保護國家的基礎設施。

01

個人終端設備資安防護

該如何避免惡意程式或駭客的攻擊？

謹慎處理陌生人的郵件、即時更新軟體、遵守公司資安政策、不瀏覽非公務網站、不安裝非業務所需軟體，並安裝 IRMAS 與防毒軟體。以下為個人終端設備的六項防護措施。

IRMAS 實際畫面

安裝 IRMAS 後，請依序確認以下畫面。點選圖片可放大檢視。

01 / 06

安全查核：確認無需要修正項目

開啟本機 IRMAS，點選「安全查核」，狀態須為藍燈並顯示「您目前沒有安全查核項目需要修正」。

02 / 06

弱點管理：確認無需要更新項目

點選「弱點管理」，須為藍燈並顯示「您目前沒有修補程式需要更新」。亮紅燈代表查核到未安裝的修補程式，請儘快執行 Windows Update。

03 / 06

系統資訊：記錄使用人與資產 ID

點選「系統資訊」，記下「使用人」及「資產ID」。之後以該使用人帳號登入 IRMAS 網站，檢查此資產 ID 設備是否有違反查核項目。

04 / 06

IRMAS 網站：逐一檢查安全查核項目

在 IRMAS 網站點選該設備的 IP 位址進入，逐一檢查安全查核項目，欄位空白表示合規。違反項目會以紅色叉叉註記（例如未安裝防毒軟體），請依指引修正。

05 / 06

病毒碼版本己過期：立即更新

安全查核出現「病毒碼版本己過期」時，開啟防毒軟體（OfficeScan），點選「更新」，以免終端未受最新版防毒軟體保護。

06 / 06

修正後：資料同步更新

修正完成後點選「資料同步更新」（或重新開機），直到 IRMAS 網站上的更新時間晚於本機確認無弱點的時間，才表示已同步完成。

安裝 IRMAS 與設定場域

場域決定 IRMAS 派送哪些管控措施。選錯場域會派送錯誤的管控措施，影響日常作業或管控不足。

  1. 前置條件新設備主機已於 ICTINV 系統申請資產 ID 並設定預設場域；先完成 Windows Update 與安裝防毒軟體，安裝會較順利。
  2. 安裝讀卡機與 HiCOS_Client並以 HiCOS 卡片管理工具確認讀得到員工卡。
  3. 確認資產 ID 未重複若 IRMAS 網站上已有此資產 ID，需先請管理者刪除或遠端移除 Agent，否則會出現「連線或認證失敗！」並終止安裝。
  4. 以系統管理者身分執行安裝檔插卡認證時，OA 環境選 OA Version 的「OA」；在家或國外選「Internet」。
  5. 靜置約 5 分鐘等待認證畫面自然出現，期間請勿重開機或自行開啟程式，否則會安裝失敗。
  6. 輸入 PIN 碼與資產 ID資產 ID 可至 ictinv.cht.com.tw/irmas.html 查詢，英文字母需大寫。該主機需於 ICTINV 上設定使用場域。

場域選定後，無法從 Agent 端再修改；如需變更，請至 IRMAS 管理網站提出申請。

資訊負責人負責哪些事

每個單位都有一位資訊負責人，是同仁遇到電腦或資安問題時的第一個窗口，也就是通報流程中的「單位資安幫手」。主要負責以下四項工作：

01電腦設備簡易障礙排除與報修電腦無法開機、連不上網路、印表機等周邊故障時，先找資訊負責人排除，必要時由他協助報修。
02IRMAS 查核與更新協助確認單位內每部電腦都已安裝 IRMAS、場域正確、燈號為藍燈，並處理查核不合規的項目。
03年度電腦及終端設備申請彙整單位年度的電腦與終端設備需求並提出申請，需要新設備請先告知他。
04電腦 IP 位址管控管理單位內電腦的 IP 位址（IPAM 平台）。新電腦需要 IP，或電腦要搬位置、換網段時，請先找他。

資料安全注意事項

  1. 極機密級資料未經權責主管授權，不得使用電子郵件傳送。傳遞及存取安全
  2. 機密級以上資料，依存在形式與儲存媒體，於明顯處標示安全等級，標示應涵蓋完整資料內容。識別安全
  3. 機密級以上資料儲存時應加密；傳輸時應採用具加密機制之電子郵件服務。儲存及傳遞安全
  4. 內部檔案應標註資料安全等級，限閱級以上不得任意散布或儲存至公司外部。識別及存取安全
  5. 限閱級以上資料不得存放於外部網路分享空間（如 Google Drive），不得透過 LINE、FB、ChatGPT 談論、傳輸或揭露公務。傳遞、儲存及存取安全
  6. 因業務需要交換/存取限閱級以上資料時，如存放於 boxe 須將檔案加密，並於兩周內刪除不必要檔案。儲存及存取安全

常見問答

從 EIP 下載 7-Zip 時有 x64 和 x86 兩個檔案，該選哪個？
看你的 Windows 位元數：64 位元請下載 7-zip_x64，32 位元請下載 7-zip_x86。EIP 上其他有分位元版本的免費軟體也是同樣原則。
第一次從 EIP 下載檔案，為什麼要裝東西？
第一次下載需先安裝客戶端元件，才能驗證識別證 PIN 碼。依序點選執行→確定→安裝→完成，之後插入識別證輸入 PIN 碼登入即可。
電腦重灌後要先裝什麼？
先裝防毒軟體，再裝 IRMAS。
要傳少量機敏文件給外部，可以用 LINE 或 Google Drive 嗎？
不行。限閱級以上資料不得透過傳訊軟體或外部分享空間傳輸。少量機敏文件請使用安全電子郵件（EIP →資源共享→軟體下載→資安軟體→電子郵件簽章與加密）。
收到 CHTSOC 事件單怎麼辦？
立即處理並回覆，切勿逾期。依事件等級於 ISTMS 回報，逾期會升級通知你的主管。
電腦有問題要找誰？
先找你單位的資訊負責人（第三章可搜尋），負責設備簡易障礙排除與報修、IRMAS 查核與更新、年度設備申請與 IP 管控。
